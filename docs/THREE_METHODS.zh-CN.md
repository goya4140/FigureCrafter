# FigureCrafter 的三种方法

我们希望研究：在同一套科研内容理解、参考学习和质量审查机制下，改变绘制后端，会怎样影响科学准确性、视觉表现力、可编辑性和修订成本。三个版本是同一框架的不同输出路径；Native 的基线为原版 v2.5.1。

## 共同部分

当前输入统一为数据集处理好的论文 Method 原文和三张有序参考 PNG。Method 提供科学依据；参考提供视觉证据，不能将参考论文的模块、结论或公式移植到当前论文。历史 PDF 输入实验单独保留和标注。

模型完整读取四份指南与科学输入，实际观察参考图片，完成科学理解、参考学习、科学与视觉表征、布局及绘制决策。颜色、层级、几何、信息密度和风格根据当前输入决定，没有固定浅色卡片、统一配色、标签上限或作者代码长度上限。

每条路径都保留实际输出、全图与出版尺寸预览、科学和视觉审查、修订决策、来源及输入哈希。机械通过、成功生成、作者模型接受和独立评审是不同状态。画布为横向 16:9；必要的等比例处理或白边必须披露，不能非等比拉伸。

## Native：直接生成可编辑图

流程：Method 与参考 → 理解与表征 → 模型编写完整作者代码 → 生成原生 PPTX → 实际渲染 → 模型查看全图、出版预览与局部 → 修订原生对象 → 审查、选择与冻结。

代码执行器不替模型规划图，也不提供样例专用布局。文字、形状、连线、组合数学等可以保留为对象；真实照片和不可再分的视觉资产可以是局部图像。PPTX 可编辑不代表每个对象都天然正确，也不代表数学一定具有 OfficeMath 语义。

适合需要明确控制文本、公式、几何、连线和后续修改的使用场景。局限需要从实际结果判断：原生代码实现细腻视觉内容所需的工作可能较多。

## Image：图像模型作为最终绘制出口

流程：同样的 Method 与参考 → 模型理解、参考学习、表征与布局 → 完整绘图提示词及三张参考 → 图像模型生成 → 实际像素审查 → 在允许预算内 image edit → 选择 PNG / 栅格 PDF。

提示词由 FigureCrafter 基于 Method 组织，包含科学叙事、关键实体与关系、公式、组成与位置、参考迁移方式及不可编造内容。当前零 edit 实验的 Nano 实际输入是该提示词、三张参考图和生成参数，并非整个 GPT 会话或框架源码。原始 Method 不作为独立附件发送给 Nano；科学信息已经进入绘图提示词。

通用版本最多累计 3 次 edit，失败与分支也占预算；零 edit 实验只输出初稿。Image 不把原生 coding 修图伪装成 image edit，不声称一张 PNG 具有 PPTX 对象级编辑能力。

它检验图像模型能否更好表达示意场景、空间关系、纹理与复杂视觉组合，同时记录文字、公式、因果关系和多轮编辑退化等实际问题。

## Hybrid：图像方案转原生对象，再完善

流程：图像方案 → 当前图片的 SAM3 / PP-OCRv5 → 实际查看候选框、文字和覆盖缺失 → Decomposer Recognition / Representation / Composition / Refinement → 可编辑 PPTX 与场景、资产、预览 → FigureCrafter 导入 → 原版对象级审查与修改 → 实际渲染、复审与冻结。

Decomposer 承担重建。FigureCrafter 接收实际 PPTX，打开并修改其中的对象，保留有用的构图与图像表现力；它不代替 Decomposer 从零手工重画。图像方案和重建检查点不可覆盖，最终审查也不能仅凭重建像素分数放行。

Method 仍是科学依据。当图像方案出现错误时，最终图应修正错误；科学纠错造成的像素变化与无意的视觉损失需要分别说明。保留原子图片不等于图片内部可编辑；图片字节、裁剪与显示比例也分别核验。

当前配对探索直接复用已有 Image 零 edit 初稿，避免独立再生成一张图。这样可以具体观察从同一张图到重建、再到完善的变化。早期 RoboScape 的 Image 与 Hybrid 方案独立生成，不能将其冒充这轮配对协议。

## 区别与验证目标

| 比较维度 | Native | Image | Hybrid |
| --- | --- | --- | --- |
| 首次绘制 | 代码创建原生对象 | 图像模型生成位图 | 图像模型生成视觉方案 |
| 重建环节 | 无 | 无 | Decomposer |
| 后续修改 | 原生对象 | image edit | 原生对象；当前配对实验无 image edit |
| 最终输出 | PPTX / PDF / PNG | PNG / 栅格 PDF | PPTX / PDF / PNG |
| 视觉能力来源 | 模型设计与代码表达 | 模型设计与图像生成 | 图像生成、重建保留及原生完善 |
| 特有风险 | 对象实现与视觉细节质量 | 文字/公式及全图编辑退化 | 重建损失、对象粒度、接续修订的视觉退化 |
| 直接测量 | 科学/视觉质量、可编辑性、成本 | 科学/视觉质量、生成与编辑成本 | 三阶段视觉保留、科学修复、可编辑性、累计成本 |

这些实验能够比较后端与表示选择的实际取舍。它们尚不能凭单个漂亮案例证明某条方法普遍更好。正式比较需要相同 Method 与参考、模型及预算记录、明确是否共享中间图，以及独立的科学/视觉和编辑性评估。

## 已有证据

RoboScape 的历史 Hybrid 完成重建与原生修订，保留了 27 个原子图片字节及 363 个导入对象身份，作者模型复审通过；其重建像素相似度 0.937014 低于当时 0.94 阈值，没有被改写成保真通过。该实例未做 PowerPoint/WPS 现场交互验证。

当前 Nano 零 edit 集合有 52/60 张；生成成功不等于最终质量通过。三例配对 Hybrid 由另一个实验任务执行，本仓库此版只收录已完成、可核对的历史 Hybrid 交付，不从运行中目录抢取最终结果。[实际案例与局限](../showcases/figurecrafter/README.md)。
